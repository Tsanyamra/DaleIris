# DaleIris

Analyzes and visualizes system performance metrics for IT administrators and DevOps teams in a web-based dashboard.

DaleIris is aimed at developers who need a straightforward, dependable solution.

## Installation

1. Clone the repository: `git clone https://github.com/yhonaach/DaleIris.git`
2. `cd DaleIris`
3. Install in editable mode: `pip install -e .`

## Configuration

To configure DaleIris, modify the settings in the configuration file. Options include:
- **DEBUG**: Enable or disable debug mode.
- **ALLOWED_HOSTS**: Set allowed hostnames.
- **DATABASES**: Configure database settings.
